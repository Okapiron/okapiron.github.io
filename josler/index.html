J-OSLER登録表

症例を記録し、疾患群の充足状況を表で確認するアプリです。症例（ショート）と病歴要約（ロング）を切り替えて管理できます。

お問い合わせ・不具合報告

GitHub Issuesで受け付けています。アプリ名、端末名、iOSのバージョン、問題が起きた操作をお知らせください。投稿にはGitHubアカウントが必要です。

GitHubで問い合わせる

投稿内容は公開されます。患者氏名、患者ID、症例の詳細、バックアップファイルなど、個人情報・医療情報は記載・添付しないでください。

症例を追加する

表または症例一覧の「＋」から追加できます。タイトルだけでも保存できます。該当する疾患は複数選べます。

表の色と数字

ショートは黄色が検討中、青色が提出中、緑色が承認済、赤色が差戻しです。ロングは黄色が検討中、青色が作成済、緑色が承認済、赤色が差戻しです。数字は症例数、斜線は対象のないマスを示します。

疾患の選択と絞り込み

疾患を複数候補として選び、登録先を1つ選択できます。ショートの検討中で登録先が未選択の場合は候補の疾患に、登録先を選んだ場合はその疾患に集計します。診療科名をタップすると疾患項目を参照できます。症例一覧では診療科・登録状況・キーワードで絞り込めます。

病歴要約を管理する

症例の詳細で「病歴要約症例にする」を選ぶと、ロングの表に表示されます。ロング表示中の＋から追加した症例も、病歴要約症例として管理できます。領域別・外科紹介・剖検の枠から症例を選び、本登録と補欠を整理できます。症例の編集画面では、病歴要約メモを任意で記録できます。

保存と編集中の復元

編集は「保存」で確定します。入力途中の内容は中断時の復元用に自動退避します。未保存の編集がある場合は、登録症例画面の「編集を復元」から再開できます。設定の「データの移行・復元」では、直前の保存データを読み込めます。

機種変更・バックアップ

設定の「データの移行・復元」から「データを書き出す」でファイルを保存し、移行先で「データを取り込む」を選びます。取り込み内容を確認し、追加・更新または全置換を選択できます。端末間の自動同期には対応していません。

アプリをロックする

設定のプライバシーからロックを有効にできます。Face ID・Touch ID・端末のパスコードで解除できます。
