お問い合わせ・不具合報告

不具合やご要望はGitHub Issuesで受け付けています。アプリのバージョン、iPhoneの機種、iOSのバージョン、発生した段数、再現手順をお知らせください。

GitHub Issuesを開く →

投稿にはGitHubアカウントが必要です。投稿は公開されます。個人情報や認証情報を記載しないでください。

遊び方

PLAYで開始し、画面をタップしてブロックを重ねます。ぴったり重なるとPERFECTで幅が少し回復し、10段ごとにも回復します。

よくある質問

失敗したら？
最初から無料で再挑戦できます。1回の挑戦につき1回だけ、動画広告の視聴を選び、視聴報酬を得ると幅を回復して同じ段数から続けられます。最初から挑戦し直すと、再び1回利用できます。広告の読み込み・表示に失敗した場合や報酬を得る前に中断した場合は、回復されません。

記録はどこに保存されますか？
最高段数とPERFECTの連続記録は端末内に保存されます。独自のクラウド同期はありません。アプリを終了した後は0段からのプレイになります。

通信は必要ですか？
ゲーム本体は通信なしで遊べます。広告の利用には通信が必要です。

音や振動を止められますか？
ホームの設定から切り替えられます。

広告の設定を変更できますか？
必要な地域・状況では、設定に「広告のプライバシー設定」が表示されます。
