iPhone・iPad / 症例収集・進捗管理

J-OSLER登録表

症例を記録し、疾患群の充足状況を表で確認するアプリです。「候補・提出中・承認済」の3つの状態で整理できます。

お問い合わせ・不具合報告

GitHub Issuesで受け付けています。アプリ名、端末名、iOSのバージョン、問題が起きた操作をお知らせください。投稿にはGitHubアカウントが必要です。

GitHubで問い合わせる

投稿内容は公開されます。患者氏名、患者ID、症例の詳細、バックアップファイルなど、個人情報・医療情報は記載・添付しないでください。

症例を追加する

表または症例一覧の「＋」から追加できます。タイトルだけでも保存できます。該当する疾患は複数選べます。

表の色と数字

黄色は候補、青色は提出中、緑色は承認済です。数字は症例数、0は記録なし、斜線は対象の疾患群がないマスです。王冠は領域ごとの必要症例数・疾患群数・内訳を承認済症例で満たすと表示します。研修全体の修了を示すものではありません。

集計と絞り込み

固定していない候補は、選んだすべての疾患に集計します。登録先を固定した症例、提出中・承認済の症例は、登録先の疾患だけに集計します。診療科名をタップすると項目一覧を開き、承認済の症例がない項目や、候補も含め症例がない項目を絞り込めます。

機種変更・バックアップ

設定の「バックアップを書き出す」でファイルを保存し、移行先で「バックアップから復元」を選びます。復元は現在のデータを置き換えます。端末間の自動同期には対応していません。
